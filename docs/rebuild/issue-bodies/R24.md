## Purpose

Integrate and verify the complete personal-tracking alpha. This delivers the alpha gate outcome described below without requiring knowledge of prior conversations.

## Relevant context

SceneCask is a responsive TV-tracking web app, not a streaming service. Rust/Axum API, Next.js/TypeScript, PostgreSQL/SQLx, REST/OpenAPI generated client, server cookie sessions, email/password plus Google SSO and TMDB. Track episodes independently, including future/out-of-order watches; only explicit catch-up marks earlier episodes. Backend removes protected content. The product must work without friends. Private by default; hosted discussions require mutual approved follows plus a separate spoiler gate. Completed is computed, never a manual status.

Read [approved decisions](https://github.com/BrewingBytes/SceneCask/blob/e524b2898965cfbbdd4b0aa049c0deb999900459/docs/rebuild/decisions.md), [architecture](https://github.com/BrewingBytes/SceneCask/blob/e524b2898965cfbbdd4b0aa049c0deb999900459/docs/rebuild/architecture.md), and [canonical contracts](https://github.com/BrewingBytes/SceneCask/blob/e524b2898965cfbbdd4b0aa049c0deb999900459/docs/rebuild/contracts.md). ## Acceptance criteria

- Given fresh account/no friends, signup→verify→search→save→mark E3→next E2→catch-up→Undo→reload→logout/login preserves correct state.
- Given provider failure and concurrent edit, history survives and Undo keeps newer changes.
- Given unverified/other session, private/protected payloads are absent across API,SSR,prefetch.
